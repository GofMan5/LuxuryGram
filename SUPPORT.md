# Support

LuxuryGram is currently a source preview. Official binaries and a dedicated support community have not been published yet.

## Before opening an issue

1. Search [existing issues](https://github.com/GofMan5/LuxuryGram/issues).
2. Confirm the problem occurs on the current `dev` branch or record the exact commit you built.
3. Check whether the same behavior exists in [AyuGram Desktop](https://github.com/AyuGram/AyuGramDesktop) or [Telegram Desktop](https://github.com/telegramdesktop/tdesktop).
4. Collect minimal reproduction steps and sanitized logs.

Use the [bug report form](https://github.com/GofMan5/LuxuryGram/issues/new?template=BUG_REPORT.yml) for defects and the [feature request form](https://github.com/GofMan5/LuxuryGram/issues/new?template=FEATURE_REQUEST.yml) for proposals.

## Protect your account

Never post your phone number, login code, API hash, `tdata`, session files, private messages, or an unredacted `log.txt`. Project maintainers do not need remote access to your account to investigate a normal bug.

Security vulnerabilities belong in [private vulnerability reporting](https://github.com/GofMan5/LuxuryGram/security/advisories/new), not public issues.

## Scope

This repository handles LuxuryGram-specific source, build, and packaging issues. Platform-wide Telegram service problems and bugs reproducible in the official client should be reported through [Telegram's bug tracker](https://bugs.telegram.org/).
