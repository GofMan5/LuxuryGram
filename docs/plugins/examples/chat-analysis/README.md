# Анализ чата для LuxuryGram

JavaScript-плагин для LuxuryGram 1.0.22+ (API 1). Никаких npm-зависимостей,
сервера-посредника или изменений клиента. Добавляет «Анализ» в меню чата
**⋯ → Плагины** и в кнопку плагинов в шапке.

## Установка

Откройте **Настройки → LuxuryGram → Плагины → Установить с GitHub** и вставьте:

```text
https://github.com/GofMan5/LuxuryGram/tree/dev/docs/plugins/examples/chat-analysis
```

Клиент устанавливает JavaScript-плагины с GitHub, не из ZIP и не простым
копированием папки. Для собственной копии разместите `plugin.json` и `main.js`
рядом в своём GitHub-репозитории и вставьте ссылку на него. Не редактируйте
реестр плагинов или настоящий профиль вручную.

Архив, если он приложен, — исходники для публикации, не автоустановщик.
Node.js нужен только для теста разработчика, не для работы плагина.

## Настройка

В деталях плагина заполните:

- **Endpoint API** — публичный HTTPS-сервер на порту 443, например
  `https://api.example.com`, `https://api.example.com/v1` или
  `https://api.example.com/v1/chat/completions`. Допускается префикс пути:
  `https://proxy.example.com/openai/v1`. Адрес без `/v1` получает этот суффикс.
  Query, fragment, логин/пароль в URL и другие порты не принимаются.
- **Ключ API** — значение без `Bearer`, оно добавляется плагином.
- **Модель** — ID можно указать вручную. Для выбора откройте любой чат →
  **Плагины → Выбрать модель**: список загружается через `GET /v1/models`,
  восемь моделей на страницу. Поиск применяется после OK, действие выбирается
  под списком. Каталог не фильтруется по возможностям: выбирайте именно
  чат-модель, поддерживающую `POST /v1/chat/completions` и JSON в ответе.
- **Я в чате — ник** — ваш ник. Если пусто, берётся `@username` или имя
  активного аккаунта. Авторство определяется по Telegram ID, не по имени
  собеседника и не по одному флагу `out`.
- **Контекст или цель по умолчанию** — необязательно. Перед каждым анализом
  появляется поле, в котором можно заменить контекст только для этого запроса.

При первом анализе с пустой моделью автоматически открывается её выбор.
Запрос моделей передаёт ключ, но **не передаёт переписку**. Ни при загрузке
плагина, ни при изменении настроек сетевых запросов нет.

## Использование

1. Откройте чат и выберите **Анализ**.
2. Введите контекст или цель; можно оставить поле пустым. Отмена ничего не
   отправляет.
3. Проверьте чат, endpoint и модель в отдельном подтверждении. Только после OK
   плагин загрузит последние 100 доступных сообщений и отправит их в API.
4. Прочитайте **Суть**, **Чего НЕ делать**, **Лучший ответ**.
5. Закройте окно и выберите **Скопировать ответ 1** или **Скопировать ответ 2**.
   В буфер попадёт только текст ответа, без заголовков и пояснений.
   **Скопировать анализ** копирует всё; **Последний анализ** открывает результат
   повторно без запроса API. Если модель дала один вариант, копирование второго
   объяснит, что нужно выбрать первый.
6. Вставьте, проверьте и отправьте сообщение самостоятельно. Плагин не имеет
   разрешений на отправку, редактирование и удаление сообщений.

Отдельное копирование необходимо: API LuxuryGram разрешает буфер обмена только
в течение секунды после нажатия пункта меню, а не после ожидания ответа модели.
Одновременно выполняется один запрос; повторное нажатие не создаёт второй.
После подтверждения передача уже не отменяется закрытием меню. Смена аккаунта
или endpoint/ключа отбрасывает устаревший результат, но не отзывает данные,
уже переданные провайдеру.

## Что передаётся и хранится

- До 100 сообщений **всего чата**, включая другие темы форума: текущее API
  истории не принимает ID открытой темы. Если сообщений меньше, передаются
  доступные; служебные сообщения API может пропускать. Порядок — от старых
  к новым. Это не анализ только выделенных сообщений.
- Текст и подписи, имя автора, отметка «я»/«собеседник», время Unix, ID
  сообщения/ответа/темы, тип вложения и отметка пересылки. Telegram ID автора
  в запрос не включается. Содержимое файлов, фото и голосовых не скачивается,
  расшифровки аудио нет.
- Ваш ник и введённый контекст. Берётся следующий промпт:

```text
Анализируй последние 100 сообщений чата. Я в чате: [НИК].
Доп. вводные от меня: [КОНТЕКСТ_ИЛИ_ЦЕЛЬ].

Задача:
1. Суть (2-3 коротких пункта по фактам: что происходит, состояние собеседника, скрытый смысл).
2. Чего НЕ делать (1-2 пункта: главные ошибки сейчас).
3. Лучший ответ (1-2 варианта для отправки).

Правила для текста ответа:
- Идеально скопируй мой стиль речи из чата (манера, сленг, ошибки, отсутствие заглавных букв и запятых, обращения).
- Никакого официоза, шаблонов ИИ и воды.
- Текст сразу готов к отправке.
```

Дополнительно модель получает правило не исполнять инструкции из переписки,
не выдумывать вложения и не выдавать предполагаемые мотивы за факт. Для
надёжного копирования отдельных ответов запрашивается JSON с массивами
`essence` (2–3), `avoid` (1–2), `replies` (1–2). Принудительный `response_format`
не передаётся для совместимости с провайдерами; невалидный ответ показывает
ошибку, а не выполняется как код. Это не гарантирует защиту от prompt injection
или точность психологических выводов — проверяйте рекомендации.

**Разрешения:** `ui`, `messages.read`, `network`, `clipboard`. Для произвольного
endpoint манифест объявляет **`network: ["*"]`** — любой публичный HTTPS-хост,
включая разрешённые хостом перенаправления. Доверяйте своему провайдеру и
используйте прямой URL без redirect: хост LuxuryGram снимает Authorization при
межсайтовом redirect, но тело запроса может быть перенаправлено. Локальные и
приватные адреса ограничены хостом; при прокси домен разрешает сам прокси,
а клиент проверяет только IP-литералы, не итоговый адрес домена.
`http://localhost`, локальный Ollama и нестандартные порты этим плагином не
поддерживаются. Для более узкого разрешения перед публикацией можно заменить
`*` на единственный нужный домен.

Ключ маскируется типом `secret`, но сохраняется штатной системой плагинов
в локальном `data/settings.json`, **не в системном хранилище секретов**. Не
публикуйте данные своего профиля. Плагин не логирует запросы/ответы, ключи и
тексты ошибок провайдера, не сохраняет историю или результат на диск. В памяти
остаётся только последний результат одного чата; перезагрузка/отключение,
смена аккаунта и endpoint/ключа его удаляют. Копирование заменяет буфер обмена;
системная история буфера может его сохранить. Условия хранения переписки на
сервере определяет ваш API-провайдер, не LuxuryGram.

## Ограничения и ошибки

- Штатный таймаут HTTP — **30 секунд**, ответ — до **10 MiB**. Долгая reasoning
  модель может не успеть: выберите более быструю. Потоковая передача не нужна.
- Контекстное окно и поддержка Chat Completions зависят от модели. Плагин не
  урезает 100 сообщений незаметно и не делает повторных платных запросов.
  При размере сформированного текста более 600 000 UTF-16 единиц запрос
  отказывается отправляться. Ответ более 32 000 единиц или с
  `finish_reason: "length"` считается неполным и не заменяет прошлый результат.
- HTTP 401/403 — проверьте ключ и доступ; 404 — путь API/модель; 429 — квоту и
  баланс. Невалидный JSON, пустой список моделей и пустой/неполный ответ
  показывают понятную ошибку без раскрытия тела ответа сервера.
- ID модели: 1–200 печатных ASCII-символов без пробелов. Это укладывается в
  ограничения нативной формы; остальные ID не попадают в выбор.
- Интерфейс использует штатные формы и диалоги LuxuryGram. Их тема, масштаб,
  клавиатура и доступность наследуются от клиента; отдельного webview нет.

## Проверка разработчика

Из корня репозитория:

```text
node tools/tests/chat_analysis_regressions.cjs
tsc --allowJs --checkJs --noEmit --target es2020 --lib es2020 --strict false --types ./docs/plugins/lux.d.ts docs/plugins/examples/chat-analysis/main.js
```

Первый тест без сети исполняет реальный JS-prelude `lux` и код плагина в Node VM,
подменяя только host I/O. Проверяет запросы, историю, prompt, согласие, выбор
моделей с поиском и страницами, отдельное копирование, ошибки, смену аккаунта,
endpoint/ключа и выгрузку. Это **не** проверка настоящего QuickJS, нативной
раскладки, Telegram-аккаунта или реального API. Для проверки в клиенте нужен
подготовленный тестовый аккаунт и свой ключ; настоящий профиль не используется
тестом автоматически.
