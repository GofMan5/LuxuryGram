## Почему LuxuryGram

<table>
  <tr>
    <td width="50%" valign="top">
      <h3>Приватность на ваших условиях</h3>
      Читайте чаты и истории без отметок о прочтении, печатайте без индикатора набора и появляйтесь в сети, только когда решите сами. Режим стримера скрывает окно от захвата экрана в Windows и macOS.

  </tr>
  <tr>
    <td width="50%" valign="top">

      Устанавливайте плагины на JavaScript по ссылке на GitHub. Каждый работает в своей песочнице и получает только те разрешения, которые вы одобрили.
    </td>
    <td width="50%" valign="top">
      <h3>Доверие, которое можно проверить</h3>
      Открытый код, сборки только в этом репозитории с контрольными суммами SHA-256 и самообновление, которое отклоняет любой пакет с непроверенной подписью.

### А также

- **Фильтры и теневой бан.** Скрывайте спам и нежелательных отправителей фильтрами на регулярных выражениях, теневой бан скрывает человека без блокировки, а наборами фильтров можно делиться через импорт и экспорт.
- **Меню сообщений для опытных.** Подробные сведения о сообщении и его повтор в один клик правой кнопкой, пересылка без отправителя или подписи, а также сразу в «Избранное».
- **Расширенный музыкальный плеер.** Обложка, перемотка, управление и кнопка сохранения обложки.
- **Telegram без лишнего.** Отключайте истории, рекламу, похожие каналы и предупреждения о ссылках, снимайте ограничения на выделение и стикеры, фильтруйте текст Zalgo.
- **Производительность под ваш процессор.** Фоновая работа подстраивается под CPU, одно ядро всегда остаётся интерфейсу, а первые кадры видео, кэш кастомных эмодзи и файлы анимированных стикеров декодируются вне потока интерфейса.

Всё находится в **Настройки › Настройки LuxuryGram**, раздел открывается и из бокового меню. Часть возможностей работает только на вашем устройстве и не меняет поведение серверов Telegram.

## Плагины

Плагин — это репозиторий GitHub с `plugin.json` и модулями на JavaScript. LuxuryGram скачивает перечисленные файлы, показывает все запрошенные разрешения и запускает код в песочнице QuickJS без доступа к файлам и процессам. Методы входа, сеансов и паролей, а также траты Stars и денег плагину недоступны никогда, как и служебный чат с кодами входа и ваш номер телефона. Плагины доступны начиная с LuxuryGram 1.0.22.

Полноценный плагин с командой `/hello` требует одного разрешения:

```json
{
  "id": "com.yourname.hello",
  "name": "Hello",
  "version": "1.0.0",
  "api": 1,
  "runtime": "js",
  "main": "main.js",
  "permissions": ["ui"]
}
```

```js
lux.ui.addCommand({
  name: 'hello',
  description: 'Say hello',
  handler: ({ peer, args }) => lux.ui.toast(`Hello, ${args.trim() || peer.title}!`),
});
```

Опубликуйте его на GitHub, откройте **Настройки › Настройки LuxuryGram › Плагины › Установить с GitHub** и вставьте `yourname/repo`. Начните с [руководства автора](docs/plugins/AUTHORING.md), типов [`lux.d.ts`](docs/plugins/lux.d.ts) и [примера hello-world](docs/plugins/examples/hello-world/); полный контракт описан в [архитектуре плагинов](docs/plugins/ARCHITECTURE.md).

## Вопросы и ответы

<details>
<summary><strong>Безопасно ли устанавливать LuxuryGram?</strong></summary>
<br>
Исходный код открыт, а официальные сборки публикуются только в разделе <a href="https://github.com/GofMan5/LuxuryGram/releases">Releases</a> этого репозитория, каждая с файлом <code>SHA256SUMS.txt</code>, по которому загрузку можно проверить до запуска. Цифровой подписи у архивов нет, поэтому Windows SmartScreen может предупредить при первом запуске. Если ваша модель угроз требует независимой проверки, изучите код и <a href="#сборка-из-исходников">соберите приложение сами</a>.
</details>

<details>
<summary><strong>Могут ли ограничить аккаунт за использование LuxuryGram?</strong></summary>
<br>
Это возможно, как и с любым сторонним клиентом. LuxuryGram работает с Telegram через тот же публичный API, что и другие клиенты, а Telegram может ограничить любой аккаунт по своему усмотрению. Ни один неофициальный клиент не может гарантировать обратного. Функции вроде режима призрака меняют только то, что отправляет и показывает ваш собственный клиент; пользуйтесь ими, понимая это.
</details>

<details>
<summary><strong>Как работают обновления?</strong></summary>
<br>
Приложение проверяет этот репозиторий на новый релиз, скачивает его и сверяет подпись ключом LuxuryGram до распаковки. Пакет, не прошедший проверку, отклоняется. Автообновление отключается в <strong>Настройки › Продвинутые настройки › Обновлять автоматически</strong>.
</details>

<details>
<summary><strong>Есть ли версия для macOS?</strong></summary>
<br>
Готового пакета пока нет. Опубликованы архивы для Windows x64 и Linux x64; для macOS есть <a href="docs/building-mac.md">инструкция по сборке</a>.
</details>

<details>
<summary><strong>Покидают ли сохранённые удаления и правки мой компьютер?</strong></summary>
<br>
Нет. Удалённые сообщения, история правок и данные Watcher хранятся локально вашим клиентом. Они не меняют того, что видят другие люди и серверы Telegram.
</details>

## Установка

Скачивайте только из раздела [Releases](https://github.com/GofMan5/LuxuryGram/releases). Не доверяйте установщикам и архивам, которые не приложены к релизу здесь.

| Платформа | Файл | Как запустить |
| --- | --- | --- |
| Windows x64 | `LuxuryGram-<версия>-win-x64-portable.zip` | Распакуйте, запустите `LuxuryGram.exe` |
| Linux x64 | `LuxuryGram-<версия>-linux-x64.tar.xz` | Распакуйте, запустите `LuxuryGram` |

Сверьте загрузку с `SHA256SUMS.txt` из того же релиза:

```bash
sha256sum -c --ignore-missing SHA256SUMS.txt
```

```powershell
certutil -hashfile LuxuryGram-<версия>-win-x64-portable.zip SHA256
```

## Сборка из исходников

Клонируйте репозиторий вместе с подмодулями:

```bash
git clone --recursive https://github.com/GofMan5/LuxuryGram.git
cd LuxuryGram
# если уже клонировали без --recursive:
git submodule update --init --recursive
```

Дальше следуйте инструкции для своей платформы: [Windows](docs/building-win.md) · [macOS](docs/building-mac.md) · [Linux с Docker](docs/building-linux.md).

Для собственной сборки нужны личные [Telegram API credentials](docs/api_credentials.md). Не публикуйте и не добавляйте их в Git.

## Безопасность и приватность

- Загружайте сборки только со страницы релизов этого репозитория и сверяйте контрольную сумму.
- Не публикуйте API hash, номер телефона, коды подтверждения, данные сессии и неочищенные логи.
- Сообщайте об уязвимостях приватно по инструкции из [`SECURITY.md`](SECURITY.md).
- Устанавливайте плагины только от авторов, которым доверяете, и читайте разрешения перед согласием.

Ни один сторонний Telegram-клиент не устраняет риски ограничений аккаунта, изменений протокола, заражённого устройства или небезопасных сборок и плагинов.
